Overview

This assignment introduces you to jamovi, the software we will use throughout the semester for statistical analysis. Your only goals this week are to (1) get jamovi installed and running on your own computer, and (2) become comfortable opening a data file and understanding what you are looking at — the variables, the values, and how jamovi labels different kinds of data.

This tutorial does NOT ask you to calculate anything (no means, medians, standard deviations, or graphs of variability). We will cover descriptive statistics and variability next. For now, just explore and get oriented.

Learning objectives — by the end of this assignment you should be able to:

  • Download and install jamovi on your own computer
  • Open a .csv data file in jamovi
  • Distinguish the Data view from the Variables view
  • Identify a variable's measure type (Nominal, Ordinal, Continuous, or ID) and explain what that means
  • Describe, in your own words, what each variable in a dataset represents

Part 1

Download and install jamovi

  1. Go to jamovi.org and click “Download.”
  2. Choose the version that matches your operating system (Windows or macOS). If you're unsure which to pick, choose the “solid” (not “cloud” or “rj-editor”) release — this is the standard desktop version.
  3. Install the program using the default settings. This may take several minutes.
  4. Open jamovi once installation finishes. You should see a blank spreadsheet-style window with a row of tabs across the top. We'll explore these in Part 4.

If you run into installation trouble (e.g., a Chromebook, a locked-down laptop, or an unsupported OS), you can also use jamovi's cloud version at cloud.jamovi.org — no installation required. Let me know if you need help getting set up.

Variables

Shows one row per variable, listing each column's name, its measure type (Nominal, Ordinal, Continuous, or ID), and other settings.

Data

Shows your raw spreadsheet, row by row. Each row is a case (a participant); each column is a variable.

Analyses

Where you run statistical tests — t-tests, ANOVA, regression, and more. This is where we'll spend most of our time later this semester.

Edit

Lets you format and annotate the results panel — add titles, notes, and rearrange output.

Jamovi guesses each variable's measure type automatically when it imports data, but its guess is not always correct or ideal — part of your job as a researcher is to check its work. Click a variable's Measure type dropdown in Variables view to see or change the assigned type. Here's a quick reference:

Measure typeIconWhat it means
NominalThree colored circlesCategories with no meaningful order (e.g., major, handedness)
OrdinalBar chart of 3 barsCategories with a meaningful order, but unequal spacing between levels (e.g., class year, caffeine intake level)
ContinuousRulerNumeric values where the distance between numbers is meaningful (e.g., reaction time, sleep hours)
IDKey/fingerprint iconA unique identifier for each case, not meant to be analyzed as data (e.g., StudentID)

Part 5

Save your work

jamovi has its own file format, .omv, which saves your data and anything else you've set up in jamovi (variable settings, and later in the semester, your analyses and results) all in one file. Saving now means you can reopen this exact file later and pick up right where you left off, instead of re-importing the CSV from scratch.

  1. In jamovi, click the hamburger menu (☰) in the top-left corner, then choose Save As.
  2. Choose This PC (or Browse), pick a location you'll remember (like your Desktop or a course folder), and give the file a clear name — for example, YourLastName_JamoviTutorial.omv. jamovi adds the .omv extension automatically.
  3. Click Save.

This is different from the Export section at the bottom of this page. Saving here keeps your work inside jamovi; exporting at the bottom saves your typed answers on this page so you can submit them to Canvas. You'll want to do both.
